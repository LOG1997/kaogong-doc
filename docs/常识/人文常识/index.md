## 五年规划（计划）

五年计划从1953年开始制定实施；十一五开始，“五年计划”改称“五年规划”。

五年规划的时间：只需要记住十三五是2016~2020，十四五是2021-2025。两个五年恰好落在整十年上。

五年规划一以贯之的主题就是把我国建设成为社会主义现代化国家。
