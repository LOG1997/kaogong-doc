# 相似成语

* 唇齿相依/休戚与共

  唇齿相依：**地理、生存层面，长用于国与国之间**。双方互相依存，一方离不开一方。侧重依存关系，少了一方另一方就会受损。

  休戚与共：**党群关系常用，只有利害关系**，福祸共担，利害一体

* 一蹴而就/一挥而就
  
  一蹴而就：一步就成功，**侧重事情轻而易举**
  
  一挥而就：侧重写作或绘画速度快，形容才思敏捷，**专用于文艺创作领域**

* 潜移默化/耳濡目染
  
  两者都涉及不知不觉受到影响，但侧重点不同。
  
  潜移默化：强调影响是无形的，**常搭配物或事，多用于性格、习惯、作风等方面**
  
  耳濡目染：强调通过长期接触受到熏陶，**侧重影响的过程，常用于人或环境**

* 鱼龙混杂/鱼目混珠/滥竽充数/龙蛇混杂
  
  鱼龙混杂：好坏混杂（**好坏混**）
  
  鱼目混珠：假的冒充真的（**假充真**）

  滥竽充数：次品混进去充数（**次充好**）

  龙蛇混杂：好坏混杂在一起，几乎和鱼龙混杂同义。

* 相得益彰/相辅相成
  
  相得益彰：两个人或者两件事物互相配合后，双方能力和作用更能显示出来，**侧重结合后效果更突出**
  
  相辅相成：两件事物互相配合、互相补充，缺一不可，**侧重互补关系**

* 司空见惯/习以为常
  
  两者都表示“常见，不新奇”。
  
  司空见惯：侧重客观状态描述——某事很常见、不足为奇。
  
  习以为常：侧重主观适应，人们已经习惯了某种事情

* 不以为然/不以为意
  
  不以为然：不同意，不认可
  
  不以为意：不在意，不重视

* 按部就班/循序渐进
  
  按部就班：中性或者贬义词
  
  循序渐进：褒义词

* 不负众望/不孚众望
  
  不负众望：没有辜负期望
  
  不孚众望：不能让人信服

* 前仆后继/前赴后继
  
  都有奋勇前进的意思
  
  前仆后继：侧重不怕牺牲，**多用在革命、战争斗争中**
  
  前赴后继：侧重奋勇前进，不一定有牺牲，**多用于事业、建设、追梦中**

* 刮目相看/另眼相看
  
  刮目相看：**是一种纵向比较，在一个时间差后**别人取得了进步，不再使用老的眼光去看待别人
  
  另眼相看：**是一种横向比较，通常没有时间差**

* 一脉相承/薪火相传

  一脉相承：侧重总想传承的关联性，多用来比较两者，证明本质是一套东西。
  薪火相传：侧重一代代接续传递，不会中断，侧重传承这个动作、延续不断

* 明目张胆/堂而皇之
  
  明目张胆：公开放肆、毫无顾忌的做事（坏事）。明确贬义。多配“违法、犯罪”等负面行为
  堂而皇之：表面上正大光明、理直气壮的做（讽刺）。中性偏讽喻。多配“占据、登堂入室、公开场合”等，强调摆到明面上。

* 曲突徙薪/防微杜渐/未雨绸缪
  曲突徙薪：主动提前改造、采取措施，规避隐患（侧重**主动行动**去预防）。

  防微杜渐：坏事刚出苗头就只值，不让继续发展（隐患已经出现了）。

  未雨绸缪：事先做好准备。

* 细若游丝/气若游丝
  
  细若游丝：形容非常细小微弱、若有若无。适用范围较广，可用于声音（低吟、说话声）、线条/笔迹（书法牵丝、绘画界画）、气息，也可用于形容龙须面等纤细的具体事物。

  气若游丝：形容呼吸微弱，濒临断气，比喻生命垂危。专门用于人或生命体的“气息”

* 长盛不衰/经久不息
  
  长盛不衰：长久兴盛，一直保持旺盛势头，搭配对象：文化、传统、品牌、产业、生命力、魅力、影响力。褒义。
  经久不息：持续不停。重在声音、动作、反响没有停下。大多用来形容动态的、一波一波的声响或者反响。

* 走马观花/浅尝辄止
  
  走马观花：粗略地观察事物
  浅尝辄止：稍稍尝试一下就停止，比喻不肯下功夫深入钻研。
