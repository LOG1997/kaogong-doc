# 成语积累

* 按图索骥

按照事物线索去寻找事物，死守理论，不懂实际变通。
贬义（本源），中性义（现代常用）。
对象是人

* 浅尝辄止

略微尝试一下就停止，侧重行动不深入，不肯深耕。
贬义。
对象是人

* 不求甚解

不追求透彻了解，只懂得大概。
贬义。
对象是人

* 予以臧否

加以褒贬，品评好坏。多用于任务、行为、方案。
中性
对象是人、事物。

* 防微杜渐

坏思想、坏事、隐患刚露出微笑苗头是就及时制止，不让他发展壮大。
褒义。
对待不良风气应当防微杜渐。
主体一般是监管、制度、管理者；对象是坏事的萌芽。

* 因噎废食

因为怕出问题，害怕受到挫折，就干脆把本该做的事全部放弃。
贬义。
不能因为一点问题就因噎废食。
对象是人、部门、机构、决策者。

* 兹事体大

这件事干系重大，影响深远，不可轻视。句子主语必须是**某一件具体的，待决策/推进的事务本身**
中性，只陈述事情重大这个客观属性。
涉及群众利益的医保报销规则兹事体大
主体是某一件具体的，待决策/推进的事务本身

* 闻过则喜

听到批评，指出错误就高兴。形容虚心接受批评，愿意听取意见。
褒义
党员干部应当闻过则喜，自觉接受大家的监督批评。
对象是人。

* 虚怀若谷

胸怀像山谷一样宽广。形容十分谦虚，能接受别人意见。
褒义
这位前辈虚怀若谷，乐于听取后辈的不同意见。
对象是人，多用来形容有地位、学士、能力的人，比如领导、学者、前辈。一般不用来形容普通人。

* 同声相应

志趣、意见相同的人互相呼应，彼此契合。
中性，多用于褒义语境。
适用对象：人。
志同道合的研究者同声相应。

* 同气连枝

气息相通，枝条相连。泛指关系紧密
中性，常用于褒义。
适用对象：亲人同胞；共同体、族群、地区、合作伙伴。
海峡两岸同气连枝，血脉相通

* 面面俱到

各方面都照顾到，没有遗漏。
中性，根据语境定褒贬。贬义（过于泛泛反而抓不到要害）

* 火中取栗

比喻受人利用，冒险出力却一无所得。

* 离弦走板

说话做事便宜公认准则。

* 各有千秋

各有各存在的价值，比喻各人有各人的长处。

* 削足适履

比喻不合理的迁就凑合。或不顾具体实际、生搬硬套。多用于批评拘泥成规、不知变通的做法。
贬义
适用对象：常用于人（的行为、做法、策略），也可用于制度、方案、理论应用等抽象层面。
学习外国的先进经验必须结合自身实际，不能削足适履，盲目照搬。

* 狗尾续貂

比喻拿不好的东西接到好的东西后面，前后不相称、不协调。
贬义
现代最常用于文艺作品的续写、改编、接续创作
这部经典小说的续集被读者普遍认为是狗尾续貂，远不及原作的气韵。
