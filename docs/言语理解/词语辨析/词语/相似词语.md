# 相似词语语义

* 描摹/擘画

    描摹：①照着底样写和画，强调力求相似地再现原貌。②用语言文字表现人或事物的形象、情状、特性。可用于具体事物（画作、字帖、实物），也可用于抽象事物（人物性格、风格、情状）。书面语与日常用语均可，常见于艺术创作、文学描写场景。

    擘画：筹划、布置，指对事务进行全面、系统的谋划与安排。亦称“擘划”。现代用法多指向宏观、长远、战略性的规划。多用于重大事业、发展蓝图、战略布局、未来规划等宏观抽象对象。属书面语，庄重色彩浓厚，常见于政策文件、战略报告、庆典致辞等正式场合。

* 参加/参与

    参加：加入某种组织或者活动，侧重具体事件
    参与：参加、介入事务或进程，可搭配宏大历史进程

* 融合/融入

    融合：指几种不同的事物合成一体，强调相互作用后形成统一整体，原有界限趋于消融。物理层面可指熔化汇合，抽象层面可指文化、思想、产业等的结合。（a+b=c）

    融入：指融合、混入，强调一方进入另一方之中，成为其一部分。核心在于“入”的方向性，即从外部进入某个整体或环境。(a+b=b)
