# 成语解读

## 相似成语

* 唇齿相依/休戚与共
  唇齿相依：**地理、生存层面，长用于国与国之间**。双方互相依存，一方离不开一方。侧重依存关系，少了一方另一方就会受损。
  休戚与共：**党群关系常用，只有利害关系**，福祸共担，利害一体

* 一蹴而就/一挥而就
  一蹴而就：一步就成功，**侧重事情轻而易举**
  一挥而就：侧重写作或绘画速度快，形容才思敏捷，**专用于文艺创作领域**

* 潜移默化/耳濡目染
  两者都涉及不知不觉受到影响，但侧重点不同。
  潜移默化：强调影响是无形的，**常搭配物或事，多用于性格、习惯、作风等方面**
  耳濡目染：强调通过长期接触受到熏陶，**侧重影响的过程，常用于人或环境**

* 鱼龙混杂/鱼目混珠
  鱼龙混杂：好坏混杂
  鱼目混珠：巴家的冒充真的

* 相得益彰/相辅相成
  相得益彰：两个人或者两件事物互相配合后，双方能力和作用更能显示出来，**侧重结合后效果更突出**
  相父线程：两件事物互相配合、互相补充，缺一不可，**侧重互补关系**

* 司空见惯/习以为常
  两者都表示“常见，不新奇”。
  司空见惯：侧重客观状态描述——某事很常见、不足为奇。
  习以为常：侧重主观适应，人们已经习惯了某种事情

* 不以为然/不以为意
  不以为然：不同意，不认可
  不以为意：不在意，不重视

* 按部就班/循序渐进
  按部就班：中性或者贬义词
  循序渐进：褒义词

* 不负众望/不孚众望
  不负众望：没有辜负期望
  不孚众望：不能让人信服

* 前仆后继/前赴后继
  都有奋勇前进的意思
  前仆后继：侧重不怕牺牲，**多用在革命、战争斗争中**
  前赴后继：侧重奋勇前进，不一定有牺牲，**多用于事业、建设、追梦中**

* 刮目相看/另眼相看
  刮目相看：**是一种纵向比较，在一个时间差后**别人取得了进步，不再使用老的眼光去看待别人
  另眼相看：**是一种横向比较，通常没有时间差**

## 字面意思易误解的成语

* 首当其冲
  正解：最先受到攻击或者遭受灾难
  误解：首先冲击、率先行动

* 差强人意
  正解：大体上让人满意
  误解：不能让人满意

* 不刊之论
  正解：正确的不可修改的言论。刊是削除、修改的意思。
  误解：不能刊登的言论

## 固定搭配的成语

* 汗牛充栋
  只能形容书籍多，不能用于资料、文件等

* 美轮美奂
  只能形容建筑高达华丽，不能用于形容其他事物

* 巧夺天工
  只能用于人造，不能用于天然形成的事物

* 凤毛麟角
  稀少且珍贵，如果价值普通的不应该选这个词

* 方兴未艾
  只能用于正在蓬勃发展的事物，不能接已衰退或者终结的内容
