# 逻辑填空

## 破除上帝视角，做好**本句对应**

1. 前提：做好角色定位

    不要把自己带入文段的创作者角色。

2. 核心原则：优先做好本句对应

    优先在横线出现的本句寻找词义线索、搭配对象和限制条件，本句信息已经足够锁定答案，就不必过度延申，；本句信息不足时，才向上下文寻找线索。

3. 句内证据的优先级

    |证据层级|典型表现|使用建议|
    |--|--|--|
    |强证据|明确解释、固定搭配、指代对象、反义转折|可直接锁定或者大幅排除|
    |中证据|同义复现、程度变化、感情色彩、结构对应|与词义辨析结合使用|
    |弱证据|文段主题、常识联想、整体印象、个人语感|只能辅助验证、不能单独锁定答案|

## 题目抓手

适当的联系上下文，但不是理解全文。

### 标点符号

 1. 单顿号（A、B）：通常是同义并列。通常处于同一语法层级，在语义方向、感情色彩或句法功能上往往保持一致。此时优选近义词。【不通常情况：单顿号之间带逻辑词连接，则优选反义并列】

 2. 多顿号（A、B、C）：同层级，不同义。通常是同一层级列举不同方面。横线处应该与已有项目保持一致，并尽量避免概念重复；如果并列项含有时间、动作和流程关系，还要注意先后顺序。

 3. 双引号（“”）：关注特殊含义和形象化表达。双引号可以表示引用、特定称谓、强调、比喻和反语。通常要选择符合句中语境的**形象化表达**

 4. 破折号与冒号：常见的解释说明信号。破折号和冒号通常用于解释、说明和概括。横线词语往往是**标点后内容**的凝练表达

### 关联词——逻辑的风向标

1. 转折词：提示逻辑方向变化。转折词通常提示前后内容在观点、感情色彩或于语义方向上发生变化。横线位于转折前后，要重点寻找与另一侧相反、相对或首先的对应关系。

2. 并列词（一方面...另一方面...、同时、并且等）：可以连接同向并列，也可以连接对照关系。判断方向不能只看关联词本身，还要结合其他信息要素提示，进而判断是同义还是反义并列。

3. 递进词（不但...而且...、甚至、更等）：不仅要求前后语义方向一致，还要求后项在范围、数量、程度和语气上有所递进。

4. 因果词（因为...所以...、由于...导致...）：要求原因和结果必须在逻辑上严丝合缝，有什么样的因，就有什么样的果，严禁主管拔高。

### 固定搭配

规范文本中存在较稳定的搭配习惯。遇到熟悉搭配时，可以将其作为解题的重要线索，在选项比对过程中，优先对比。

在单独文件中查看[常见词语搭配](../词语辨析/常见搭配词语.md)

## 词语辨析

找到语境方向后，难点变为：两个词都符合大意，这时不能凭借语感，需要把待选词放到五个维度中进行比较辨析。

* 维度一：核心义与侧重点

近义词通常共享一个上位含义，但各自强调的角度不同。

* 维度二：适用范围与对象

有些词含义接近，但是搭配对象存在天壤之别。对象不匹配时，即使大意相近也不能选择。

* 维度三：感情色彩

词语可以带有褒义、贬义和中性色彩，逻辑填空时需要注意。

* 维度4：程度轻重

同一语义方向的词，程度可能不同。递进词、极端结果和程度副词，往往决定应该选轻词还是重词。

* 维度5：搭配习惯和语法功能

搭配时近义词辨析中最稳定的证据之一。要同时检查动宾搭配、主谓搭配、修饰关系和词性功能。比如：这个词能不能支配后面的宾语？能不能被前面的副词修饰？放入句子后，词性和句法成分是否完整?

## 成语辨析

做好积累

成语积累至少记录四项：核心义、适用对象、感情色彩、正确搭配。

## 考场做题

1. 保持平常心，设置合理的做题时间上限。不宜在单题上过度耗时。

2. 尊重有依据的排除，作答后及时跟进。排除后就不要随意捞回了。

3. 固化按部就班的思考路径：（1）看本句对应（2）看感情色彩（3）看上下文关联
