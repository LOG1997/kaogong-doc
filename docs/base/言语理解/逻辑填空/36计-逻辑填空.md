# 36计

## 察微计——文段特殊提示

### 形象化表达

文段中给出拟人、比喻之类的修辞手法时，选词往拟人、比喻这一方面去靠。

比如文段中给出**像树**一样的感觉，就在选项中看关于树的词语。

文段**把物拟人化**表达，那就选词往拟人化去看。

### 主题词

所填词语与主题词相对应的选项优先。

主题词有两种情况：

1. 文段中**多次出现**的词语很可能就是

2. 文段中着重强调的某个词

### 搭配对象

设空位置的词语的搭配对象是谁，要找准主体，搭配要恰当。

1. 并列结构的主体，需要词语和所有主体都搭配好。

2. 主体离设空处较远，需要看完整个句子综合考量

### 两空巧解

两空之间存在关联词，两空之间有某些句意的提示。

## 理清脉络——整体逻辑填空

提出观点，后续对观点进行解释

### 问题——对策
