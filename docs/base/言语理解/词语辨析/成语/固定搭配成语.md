# 固定搭配成语

* 汗牛充栋

形容藏书极多，书籍多到运输时牛马累得出汗、堆放时塞满屋子。

中性，形容著作、藏书丰富时也可带褒义。

仅限形容书籍、藏书、著作多，不能用于资料、文件、数据等其他事物。

汗牛充栋的藏书；著作汗牛充栋；这家图书馆的典籍汗牛充栋。

* 美轮美奂

形容房屋建筑高大华丽，也形容装饰、布置等美好漂亮。

褒义。

仅限形容建筑、房屋、装饰布置，不能用于形容其他事物（如文章、风景、服饰等）。

美轮美奂的宫殿；装饰得美轮美奂；这座新落成的剧院美轮美奂。

* 鳞次栉比

形容排列密集且整齐有序，多用于房屋、船只、店铺等**具体静止的事物**，一般就是**建筑**。核心是“**密集＋有序**”。。

主流辞书标注为中性，语境中用于描绘建筑群的秩序与规模时常偏褒义，属中性偏褒义。

只适用于具体、静止、成排成列的事物，如房屋、高楼、店铺、仓库、船只等；不用于抽象概念，也不宜用于动态或无序的人群与自然景物。常作谓语或定语，属书面语。

高楼大厦鳞次栉比；房屋/店铺鳞次栉比；鳞次栉比的建筑群；沿街商铺鳞次栉比。

* 巧夺天工

人工的精巧胜过天然，形容技艺极其精巧。

褒义。

仅限用于人造的工艺品、建筑、器物等，不能用于天然形成的事物。

这件玉雕巧夺天工；园林布局巧夺天工；技艺巧夺天工。

* 凤毛麟角

凤凰的羽毛、麒麟的角，比喻稀少而珍贵的人或物。

褒义。

仅限形容稀少且珍贵的人才或事物，价值普通的不能用此词。

这样的人才凤毛麟角；此类珍本凤毛麟角；能坚持下来的人凤毛麟角。

* 方兴未艾

事物正在兴起、发展，一时不会终止。

褒义，中性偏褒。

仅限用于正在蓬勃发展的新生事物、事业、运动、潮流，不能用于已衰退或已终结的内容。

人工智能方兴未艾；这项事业方兴未艾；绿色能源产业方兴未艾。
