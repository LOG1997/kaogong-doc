# 相似成语

* 唇齿相依 / 休戚与共

1. 唇齿相依

    双方互相依存，一方离不开另一方，侧重依存关系，少了一方另一方就会受损。

    中性。

    **多用于国与国之间，地理、生存层面**，强调客观的依存关系。

    唇齿相依的关系；山水相连，唇齿相依。

2. 休戚与共

    福祸共担，利害一体，忧喜、祸福彼此共同承担。

    褒义。

    **多用于党群关系，只涉及利害关系**，强调主观上的共担。

    休戚与共的命运共同体；同呼吸、共命运，休戚与共。

* 一蹴而就 / 一挥而就

1. 一蹴而就

    踏一步就成功，形容事情轻而易举，一下子就能完成。侧重事情轻而易举。

    中性，多用于否定句。

    多用于事业、工作、改革、学习等需要长期努力的事情，强调过程不可省略。

    一蹴而就；不可能一蹴而就；绝非一蹴而就。

2. 一挥而就

    一动笔就写成，形容写字、写文章、绘画等构思敏捷，完成很快。侧重写作或绘画速度快，形容才思敏捷。

    褒义。

    专用于文艺创作领域，如写作、绘画、书法等。

    一挥而就；提笔一挥而就；文思敏捷，一挥而就。

* 潜移默化 / 耳濡目染

1. 潜移默化

    人的思想、性格、习惯在不知不觉中受到环境或他人的影响而发生变化。强调影响是无形的。

    中性。

    常搭配物或事，多用于性格、习惯、作风、思想等方面。

    潜移默化的影响；潜移默化地改变；受到潜移默化的熏陶。

2. 耳濡目染

    耳朵经常听到，眼睛经常看到，不知不觉地受到影响。强调通过长期接触受到熏陶，侧重影响的过程。

    中性偏褒。

    常用于人或环境，侧重长期接触、熏陶的过程。

    耳濡目染；耳濡目染的影响；在家庭环境中耳濡目染。

* 鱼龙混杂 / 鱼目混珠 / 滥竽充数 / 龙蛇混杂 / 泥沙俱下

1. 鱼龙混杂

    比喻坏人和好人混在一起，好坏难分。**侧重好坏混杂**。

    贬义。

    **主要用于人**，也可用于事物，强调好坏混杂。

    鱼龙混杂；泥沙俱下，鱼龙混杂。

2. 龙蛇混杂

    比喻好人坏人混在一起，好坏难分。**与"鱼龙混杂"近义**。

    贬义。

    **主要用于人**，也可用于事物，强调好坏混杂。

    龙蛇混杂；龙蛇混杂之地。

3. 鱼目混珠

    拿鱼眼睛冒充珍珠，比喻拿假的冒充真的，以次充好。**侧重假充真**。

    贬义。

    主语只能是坏的、假的，强调以假乱真。

    鱼目混珠；鱼目混珠，以假乱真。

4. 滥竽充数

    比喻没有真才实学的人混在行家里面充数，或以次货冒充好货。**侧重次充好**。

    贬义。

    主语只能是没有本领的人，偶尔搭配作品。

    滥竽充数；不能滥竽充数。

5. 泥沙俱下

    比喻好的和坏的、不同的人或事物混杂在一起，一同显现或涌现。独有动态感与趋势性，强调在流动、发展或变革进程中好坏相伴而来。

    中性。

    **可用于人，也可用于事物**。常用于信息、文化、思潮、市场现象、社会潮流等宏观或流动性领域，强调开放、发展或变革进程中难以避免的混杂。

    泥沙俱下，鱼龙混杂；难免泥沙俱下；信息泥沙俱下。

* 相得益彰 / 相辅相成

1. 相得益彰

    指两个人或两件事物互相配合，双方的能力和作用更能显示出来。侧重**结合后效果更突出**。

    褒义。

    多用于人或事物之间的配合，强调配合后效果更显著。

    相得益彰；珠联璧合，相得益彰。

2. 相辅相成

    指两件事物互相配合、互相补充，缺一不可。**侧重互补关系**。

    中性偏褒。

    多用于两件事物之间，强调互补关系。

    相辅相成；相辅相成，缺一不可。

* 司空见惯 / 习以为常

1. 司空见惯

    指某事常见，不足为奇。侧重**客观状态描述**。

    中性。

    多用于客观描述某事常见、不新奇，对象可以是事物、现象。

    司空见惯；早已司空见惯。

2. 习以为常

    指某种事情经常去做，或某种现象经常看到，也就觉得很平常了。侧重**主观适应、习惯**。

    中性。

    多用于人，强调主观上已经习惯。

    习以为常；对……习以为常。

* 不以为然 / 不以为意

1. 不以为然

    不认为是对的，表示**不同意或否定**，不认可。

    中性。

    多用于对观点、意见、做法等表示不赞同。

    不以为然；对此不以为然；露出不以为然的神色。

2. 不以为意

    不把它放在心上，表示**不重视、不在意**。

    中性。

    多用于对事情、提醒、危险等不在意、不重视。

    不以为意；对……不以为意。

* 按部就班 / 循序渐进

1. 按部就班

    原指文章结构安排得当，后指按照一定的条理、步骤做事；也指按老规矩办事，缺乏创新。

    中性或贬义。

    多用于做事、工作、学习等，强调按步骤、按条理，也可指墨守成规。

    按部就班；按部就班地推进。

2. 循序渐进

    指学习、工作按照一定的步骤逐渐深入或提高。

    褒义。

    多用于学习、教学、工作等，强调逐步深入、由浅入深。

    循序渐进；循序渐进地推进。

* 不负众望 / 不孚众望

1. 不负众望

    没有辜负大家的期望，指表现符合或超出众人期望。

    褒义。

    多用于人、团队、作品等，强调没有辜负期望。

    不负众望；不负众望，载誉而归。

2. 不孚众望

    不能使大家信服，未符合大家的期望。

    贬义。

    多用于人、团队、作品等，强调未能让人信服、辜负期望。

    不孚众望；结果不孚众望。

* 前仆后继 / 前赴后继

1. 前仆后继

    前面的倒下了，后面的紧跟上去。形容英勇奋斗，不怕牺牲。侧重不怕牺牲。

    褒义。

    多用在革命、战争斗争等需要牺牲的语境。

    前仆后继；前仆后继，英勇奋斗。

2. 前赴后继

    前面的人上去，后面的人就跟上去。形容奋勇前进，连续不断。侧重奋勇前进，不一定有牺牲。

    褒义。

    多用于事业、建设、追梦等语境。

    前赴后继；前赴后继地投入。

* 刮目相看 / 另眼相看

1. 刮目相看

    指别人已有进步，不能再用老眼光去看他。是一种纵向比较，在一个时间差后别人取得了进步。

    褒义。

    多用于人，强调对方取得进步后改变看法。

    刮目相看；令人刮目相看。

2. 另眼相看

    指用另一种眼光看待，多指看待某个人或某种人不同于一般。是一种横向比较，通常没有时间差。

    中性。

    多用于人，强调不同于一般的看待。

    另眼相看；对……另眼相看。

* 一脉相承 / 薪火相传

1. 一脉相承

    从同一血统、派别世代相承流传下来。比喻某种思想、行为或学说之间有继承关系。侧重传承的关联性。

    中性。

    多用来比较两者，证明本质是一套东西，用于思想、文化、学说等。

    一脉相承；与……一脉相承。

2. 薪火相传

    比喻学问和技艺代代相传，也比喻种族、文化等代代延续。侧重一代代接续传递、延续不断。

    褒义。

    多用于学问、技艺、文化、精神等的代代传承。

    薪火相传；薪火相传，生生不息。

* 明目张胆 / 堂而皇之

1. 明目张胆

    形容公开地、毫无顾忌地做坏事。公开放肆、毫无顾忌。

    贬义。

    多配"违法、犯罪"等负面行为。

    明目张胆；明目张胆地违法。

2. 堂而皇之

    形容公开而不加掩饰，表面上正大光明、理直气壮，多含讽刺。

    中性偏讽喻。

    多配"占据、登堂入室、公开场合"等，强调摆到明面上。

    堂而皇之；堂而皇之地占据。

* 曲突徙薪 / 防微杜渐 / 未雨绸缪

1. 曲突徙薪

    把烟囱改建成弯的，把灶旁的柴草搬走。比喻事先采取措施，防止危险发生。侧重**主动行动去预防**，注意此时事情还没发生。

    中性偏褒。

    多用于**主动提前采取措施**、规避隐患的语境。

    曲突徙薪；曲突徙薪，防患未然。

2. 防微杜渐

    在错误或坏事**刚露出苗头**时就及时制止，不让它发展。**隐患已经出现了才采取措施**。

    褒义。

    多用于坏事、错误刚露苗头时的及时制止。

    防微杜渐；防微杜渐，防患未然。

3. 未雨绸缪

    趁着天没下雨，先修缮房屋门窗。**比喻事先做好准备**，**事情还没发生**就做准备。

    褒义。

    多用于事先做好准备、提前防范的语境。

    未雨绸缪；未雨绸缪，防患未然。

* 细若游丝 / 气若游丝

1. 细若游丝

    形容非常细小微弱、若有若无。

    中性。

    适用范围较广，可用于声音、线条笔迹、气息，也可用于形容龙须面等纤细的具体事物。

    细若游丝；声音细若游丝；笔迹细若游丝。

2. 气若游丝

    形容**呼吸**微弱，濒临断气，比喻生命垂危。

    中性偏消极。

    专门用于人或生命体的**气息**。

    气若游丝；气息气若游丝；病重气若游丝。

* 长盛不衰 / 经久不息

1. 长盛不衰

    长久**兴盛**，一直保持旺盛势头，重点在一直保持**兴盛**。

    褒义。

    搭配对象是文化、传统、品牌、产业、生命力、魅力、影响力等。

    长盛不衰；长盛不衰的经典。

2. 经久不息

    **持续不停**。重在声音、动作、反响没有停下，重点在**不停止**。

    中性偏褒。

    大多用来形容动态的、一波一波的声响或者反响。

    经久不息；掌声经久不息。

* 走马观花 / 浅尝辄止

1. 走马观花

    骑在马上看花。比喻粗略地观察事物，**在观察环节**。

    贬义。

    多用于观察、了解事物不够深入。

    走马观花；走马观花式地调研。

2. 浅尝辄止

    略微尝试一下就停止。比喻不肯下功夫深入钻研，**在投入环节**。

    贬义。

    多用于学习、研究、做事不肯深入。

    浅尝辄止；学习上浅尝辄止。

* 顾此失彼 / 厚此薄彼

1. 顾此失彼

    顾了这个，丢了那个。形容**做事**无法全面兼顾，照顾不过来。

    贬义。

    多用于做事、安排、管理**无法全面兼顾**。

    顾此失彼；顾此失彼，捉襟见肘。

2. 厚此薄彼

    重视或优待一方，轻视或怠慢另一方。指对人、对事不能一视同仁，有所偏袒、待遇不公。

    贬义。

    多用于对人、对事的**态度**，**强调主观偏心**。

    厚此薄彼；不能厚此薄彼。

* 恰如其分 / 恰逢其时

1. 恰如其分

    指说话办事十分恰当，正好达到**合适的地步**。**侧重分寸恰当**，言行或处理方式不过不失。

    褒义。

    多用于言行、处理方式、评价等分寸恰当。

    恰如其分；恰如其分地评价。

2. 恰逢其时

    恰巧碰上那个**时机**。**侧重时机正好**，事情发生在合适的时间点。

    中性偏褒。

    多用于事情发生在合适的时间点、时机正好。

    恰逢其时；生逢其时，恰逢其时。

* 海市蜃楼 / 空中楼阁

1. 海市蜃楼

    大气折射形成的自然幻景，比喻虚幻不存在的事物或可望而不可即的景象、希望。**侧重虚幻、不可触及**。

    本义中性；比喻义多含贬义或中性偏贬，需结合语境。

    本义用于自然景象；比喻义用于虚幻景象、希望、前景、计划等。

    海市蜃楼般的幻景；犹如海市蜃楼；虚无缥缈的海市蜃楼。

2. 空中楼阁

    悬在半空中的阁楼，比喻虚幻的事物或脱离实际的空想、计划、理论。**侧重脱离实际、没有现实根基**。

    贬义；文学描写虚幻景象时可偏中性，需结合语境。

    常用于计划、理论、构想、理想、方案等抽象事物，也可用于文学描写中的虚幻景象。

    空中楼阁般的构想；犹如空中楼阁；不切实际的空中楼阁。
