# 相似词语语义

<FlashCompare>

* 描摹 / 擘画

1. 描摹

    照着底样写和画，强调力求相似地再现原貌；也指用语言文字表现人或事物的形象、情状、特性。

    中性。

    可用于具体事物（画作、字帖、实物），也可用于抽象事物（人物性格、风格、情状）；书面语与日常用语均可，常见于艺术创作、文学描写场景。

    描摹人物；描摹字帖；描摹情状；描摹得惟妙惟肖。

2. 擘画

    筹划、布置，指对事务进行全面、系统的谋划与安排，亦称"擘划"。现代用法多指向宏观、长远、战略性的规划。

    中性偏褒，庄重色彩浓厚。

    多用于重大事业、发展蓝图、战略布局、未来规划等宏观抽象对象；属书面语，常见于政策文件、战略报告、庆典致辞等正式场合。

    擘画蓝图；擘画未来；擘画发展；擘画宏伟蓝图。

* 参加 / 参与

1. 参加

    加入某种组织或者活动，侧重具体事件。

    中性。

    多用于组织、活动、会议、比赛、仪式等具体事件，强调加入其中。

    参加会议；参加活动；参加组织；积极参加。

2. 参与

    参加、介入事务或进程，比"参加"更强调介入和发挥作用。

    中性。

    多用于事务、进程、决策等，可搭配宏大历史进程，语体比"参加"更正式。

    参与决策；参与进程；参与其中；参与历史进程。

* 融合 / 融入

1. 融合

    指几种不同的事物合成一体，强调相互作用后形成统一整体，原有界限趋于消融（a+b=c）。物理层面可指熔化汇合，抽象层面可指文化、思想、产业等的结合。

    中性。

    可用于物理层面的熔化汇合，也可用于抽象层面的文化、思想、产业等结合。

    文化融合；产业融合；融合发展；融为一体。

2. 融入

    指融合、混入，强调一方进入另一方之中，成为其一部分。核心在于"入"的方向性，即从外部进入某个整体或环境（a+b=b）。

    中性。

    强调一方进入另一方、从外部进入某个整体或环境。

    融入集体；融入社会；融入环境；融入其中。

* 调侃 / 揶揄

1. 调侃

    用言语戏弄、嘲笑，侧重开玩笑、逗乐，轻松随意。

    中性，语带轻松。

    多用于日常交际、轻松随意的场合，不含明显恶意。

    调侃几句；互相调侃；调侃一番。

2. 揶揄

    嘲笑、戏弄，侧重戏弄、嘲弄，带有嘲讽意味。

    中性偏贬。

    多用于带嘲讽意味的场合，语气比"调侃"重。

    揶揄一番；加以揶揄；被人揶揄。

* 突兀 / 突出

1. 突兀

    ①高耸的样子，形容山峰、建筑陡峭高起；②突然发生，出乎意料；③引申为言行、事物不协调、生硬。核心是“**不协调地高出或意外出现**”。

    中性偏贬，语境决定。形容山峰可偏中性；形容事件、言行时常带消极色彩，强调不协调与生硬感。

    可用于自然地貌、建筑，也可用于事件的发生或人的言行、观点。书面语色彩较浓。

    奇峰突兀；事情来得突兀；突兀的言行；显得突兀。

2. 突出

    ①鼓起来、凸出；②超出一般，显著；③使显现、强调；④冲出、突破。核心是“**高出、显著**”或“使之显现”。

    中性，语境决定。描述客观状态时为中性；用于“成绩突出”“表现突出”时偏褒义。

    适用范围广：具体形体（眼球、关节）、抽象表现（成绩、能力、作用、特点），以及“突出重围”的动作。

    表现突出；成绩突出；突出重点；作用突出；突出重围。

* 制约 / 约束

1. 制约

    甲事物的存在和变化以乙事物为条件，乙对甲形成限制；也指**事物之间相互限制**。核心是条件性、关联性与系统性，而非人为设定边界。

    中性，客观描述条件关系或机制作用，本身不含褒贬。

    **只用于“事”**，多用于规模较大、整体性或抽象性的事物（经济发展、产业结构、系统运行等），**不用于具体的人**。只用于书面语。

    制约发展；相互制约；受……制约；制约机制。

2. 约束

    依据规则、约定或准则对行为加以限制和管束，使不越出范围。**核心是规则性、规范性的限制**，可指向他人，也可指向自身。

    中性偏积极，常指向必要的、正当的限制，与“放任”“放纵”相对。

    可用于人和事。用于人指对言行的管束，用于事指制度规则对行为的规范；既可是他律（法律约束），也可以是自律（自我约束）。书面与口语均可。

    法律约束；自我约束；制度约束；受……约束。

* 潜藏 / 夹杂 / 渗透

1. 潜藏

    藏在隐蔽处；隐藏在显露的外表之下；蕴藏。**核心是“表里关系”**，重点在**藏**，事物隐于表层之下而不显露。

    中性，取决于所潜藏之物的性质。

    可用于具体的人或物（潜藏在某处），也可用于抽象事物（动机、风险、力量、情感）。强调隐而未显，书面语色彩较浓。

    背后潜藏着……；潜藏着力量/风险/动机。

2. 夹杂

    混杂、掺杂。指某种主体事物中夹带着另一种次要的、从属的事物，有**主从之分**。**核心是“成分关系”**，某物混在主体之中。

    中性；特定语境（口音不纯、内容不健康）可偏贬。

    可用于具体事物（声音、物质、材料），也可用于抽象事物（情感、语气、成分）。书面与口语均可。

    夹杂着……；声音/语气/情感中夹杂着……。

3. 渗透

    液体、气体逐渐透过物质；比喻一种事物、势力、观念或影响逐渐进入另一领域并产生作用。**核心是“进入关系”**，强调渐进的、由外向内并扩散的过程。

    中性，积极或消极事物均可搭配。

    物理义用于液体/气体与多孔物质；比喻义用于思想、观念、势力、文化、情感等逐渐进入某一领域或群体。多用于正式议论。

    渗透到……；渗透进……；逐渐渗透；相互渗透。

* 衍生 / 派生

1. 衍生

    现代核心义为由基础事物发展、演变出新事物。**侧重“演变”，新事物与母体是延续与变化的关系**，过程可以是渐进的，新事物可能在**性质上发生较大变化**。

    中性，所衍生之物的性质决定语境倾向。

    适用范围很广：可用于具体物质（化学衍生物、衍生品），也可用于抽象事物（意义、问题、故事、文化形态、审美价值）。书面语与正式论述中常见。

    衍生出……；由……衍生而来；衍生物/衍生品；衍生意义。

2. 派生

    引申为从一个主要事物的发展过程中分化出来。**侧重“分化”，新事物与母体是主干与分支的关系**，同源而分岔，**本质可能不变**。用于语言学（派生词）、学术（派生流派、派生结论）、逻辑数学（派生定理）等有“主干—分支”结构的领域。

    中性，客观描述分化关系。

    多用于有明确“主干—分支”结构的事物：派生词、派生流派、派生结论、派生机构等。属书面语，学术与正式论述中常见。

    派生词；派生出来；派生现象；由……派生。
