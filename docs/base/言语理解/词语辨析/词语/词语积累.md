# 词语积累

* 逡巡

有所顾虑而徘徊，迟疑不敢向前，犹豫不前
中性
适用对象：人
面对改革的难关，不能逡巡观望。

* 盘桓

徘徊，逗留，在一处来回打转。
中性
适用对象：人、云雾、飞鸟等
他在湖边盘桓。

* 龃龉

意见不合、有矛盾，产生抵触隔阂。
中性偏消极
多用于两方、多方之间：理念、观点、诉求、立场、关系、方案等
产生龃龉；发生龃龉；不无龃龉。

* 泛化

由具体的、个别的扩大为一般的。泛指将某一结论、规则或做法从特定情境推广、套用到更广泛的范围，有时含有“笼统化、扩大化”的意味。
中性
适用范围很广。
儿童在学习词汇时，常把“狗”这个词泛化到所有四足动物身上，这是一种正常的认知发展现象。

* 妥帖

不出错
搭配的事做事或者说话

* 嬗变

演变、蜕变、更替。指事物经过长时间发展后发生根本性的变化，强调变化的过程性与质变性。
历史嬗变、文化嬗变、时代嬗变、社会嬗变、核嬗变。中国传统文化在近代经历了一个深刻的嬗变过程。

* 文明跃升

人类整体文明等级的跨越，也可以指社会精神文明的进步
