# 词语积累

<FlashCard>

* 逡巡

有所顾虑而徘徊，迟疑不敢向前，犹豫不前。

中性。

适用对象是人。

面对改革的难关，不能逡巡观望。

* 盘桓

徘徊，逗留，在一处来回打转。

中性。

适用对象是人、云雾、飞鸟等。

他在湖边盘桓。

* 龃龉

意见不合、有矛盾，产生抵触隔阂。

中性偏消极。

多用于两方、多方之间：理念、观点、诉求、立场、关系、方案等。

产生龃龉；发生龃龉；不无龃龉。

* 泛化

由具体的、个别的扩大为一般的。泛指将某一结论、规则或做法从特定情境推广、套用到更广泛的范围，有时含有笼统化、扩大化的意味。

中性。

适用范围很广，对象是概念、结论、规则、做法、词语用法等。

概念泛化、规则泛化、用法泛化；儿童在学习词汇时，常把"狗"这个词泛化到所有四足动物身上，这是一种正常的认知发展现象。

* 妥帖

恰当、合适、稳妥，不出差错。形容言行、处事、安排等恰到好处。

褒义。

多用于形容人的言行、处事方式、安排、措辞、关系处理等。

办事妥帖、措辞妥帖、安排妥帖、处理得很妥帖。

* 嬗变

演变、蜕变、更替。指事物经过长时间发展后发生根本性的变化，强调变化的过程性与质变性。

中性。

多用于历史、文化、社会、时代、制度、观念等宏观层面的长期演变。

历史嬗变、文化嬗变、时代嬗变、社会嬗变、核嬗变；中国传统文化在近代经历了一个深刻的嬗变过程。

* 文明跃升

人类整体文明等级的跨越，也可以指社会精神文明的进步。

褒义。

多用于人类文明、社会形态、精神文明建设等宏观层面。

推动文明跃升、实现文明跃升、文明跃升的历史进程。

* 泛化

由具体、个别扩大为一般；语言学指词义指称范围扩大，心理学指类似刺激引发同样反应，机器学习指模型在新数据上的表现能力，日常也指把结论、规则推广套用到更广范围。

中性，语境决定；作为专业术语时为中性，“过度泛化”等表述中偏贬义。

用于词义、术语范围，条件反应与情绪反应，机器学习模型能力，以及结论、规则、概念、经验等的推广延伸。

词义泛化；刺激泛化；泛化能力；过度泛化；泛化到……

* 诉求

核心义为**陈诉与请求**，即通过语言或文字向他人或机构表达具体需求；也指追求与要求，即反映个人或群体意志的抽象主张。法律专业义指诉讼请求。

中性。词本身不预设褒贬，诉求内容的性质决定语境色彩。

个人、群体、组织均可发出诉求；对象可以是具体的他人、机构，也可以是抽象的体系或领域。常见于社会民生、公共治理、商业、教育、法律等语境，正式感较强。

表达/提出/倾听诉求；利益/情感/合理诉求；回应/满足诉求；核心诉求。

* 蒙昧

①指人类社会未开化的原始状态（如“蒙昧时代”）；②愚昧，不通事理，缺乏知识、不明事理（核心现代义）；③朦胧、迷糊；④目不明或昏暗不明（古义/文学用法）。

语境决定，主流用法偏贬义。**描述“未开化的社会阶段”时可呈中性**；指“愚昧、不明事理”时明确含贬义。

可用于人（思想混沌、缺乏教育），也可用于社会、时代、群体（文明程度低下）；也可用于文学描写中的神志模糊或景象昏暗。书面语色彩较浓。

蒙昧时代；蒙昧无知；蒙昧未开；处于蒙昧状态。

* 攫取

抓取、夺取；现代核心义为以**强力或不正当手段**掠夺、获取财物、权力、利益、资源等，**强调获取方式的掠夺性与不正当性**。特定专业语境也可指提取信息、数据。

贬义为主；仅在“抓取具体物品”或专业“提取信息”用法中可偏中性，需结合语境。

多用于财物、权力、利益、资源、地盘、信息等对象；行为主体可为个人、集团、资本、势力等。常用于批评性、揭露性语境，属书面语与正式议论。

攫取财富；攫取权力；攫取利益；攫取资源。

* 深切

①情感层面：深厚而亲切，指感情真挚浓厚（如“深切的关怀”）。②认知层面：深刻而切实，指认识或感受深入透彻（如“深切地了解”）。

褒义或中性偏积极。用于形容情感深厚或认识深刻时，带有肯定、赞许意味。

适用范围广，可用于人（关怀、思念）或抽象事物（了解、体会、同情）。书面语色彩较强，多见于正式表达与文学作品。

深切的关怀/同情/思念；深切地了解/体会到；寄予深切的期望。

* 披露

核心义为**公布、发表**，指通过正式渠道将信息、消息、计划等向公众公开；也指表露、显露内心情感或心迹。古汉语中还有陈述、表白的用法。

中性。本身不预设褒贬，所披露内容的性质决定语境倾向。

主要用于正式、公开的信息发布场景，对象多为消息、真相、信息、数据、计划、细节、心迹、感情等。行为主体通常是机构、媒体或正式场合中的个人。属书面语与正式口语。

披露真相/消息/信息/细节；公开披露；信息披露；披露心迹/真情；全文披露。
