# 常见搭配的词语

锚定——目标：锁定、确定目标。

经济循环——打通

供需——匹配/平衡

波澜壮阔——发展史/史诗/历史

当仁不让——主角

<FlashCard>

- 画蛇添足
  - 贬义
  - 含义：比喻做了多余的事，反而不好。
  - 搭配：画蛇添足地加了一句
  - 适用对象：形容做事过头、多此一举的人

- 锦上添花
  - 褒义
  - 含义：比喻好上加好，美上添美。
  - 搭配：锦上添花的事
  - 适用对象：形容在已有基础上进一步完善

- 不胫而走
  - 中性
  - 含义：比喻消息等不用宣传就迅速传播。
  - 搭配：消息不胫而走
  - 适用对象：形容消息、传闻传播极快
