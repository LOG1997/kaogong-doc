# 语句排序

## 方法

一定要从选项入手，选项中有很多提示

注意观察句子开头，常常存在标志性提示词

### 第一步：对比选项，确定首尾句；形式和内容都要对比（选项中给出的首句和尾句）

首句特征：下定义、背景引入（有可能有这样的特征）

非首句特征：指代词指代不明确的；关联词后半部分；举例子；数据

尾句特征：对策或结论

### 第二步：对比选项，找差异；对比文段，找线索（同时进行）

1. 确定捆绑集团：

    指代词：这、那、它、其、该、此；这些、那些、他们

    关联词：转折（意思相反）并列（意思相同）、递进（意思相近、程度前轻后重）

2. 确定行文逻辑顺序

    有如下分类：观点+解释说明；提出问题+做出回答（问题+对策）；A+B结构，先A后B。

3. 确定日常逻辑

    1）时间顺序：年代；朝代；早期、后来、现在

    2）空间顺序：上山/下山

    3）发展顺序：相识/相知/相爱
