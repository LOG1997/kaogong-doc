# 作文热点

## 碳达峰 碳中和

1. 碳达峰：我们国家的目标是2030 年前碳达峰。到 2030 年之前，全国二氧化碳排放量涨到最高点，之后慢慢降下来，触顶回落。

2. 碳中和：目标2060 年前实现碳中和。生产、生活排碳会通过森林、湿地、海洋吸收二氧化碳，加上碳汇交易、节能改造、新能源减排，把排放出去的碳全部抵消掉，最后“收支相抵”，净排放≈0。

* 例子

    推进碳达峰碳中和，不是短期任务，不是为应付考核的一阵风，而是政府立足长远、对子孙后代负责的担当。摒弃 “先污染后治理” 的短视老路，主动布局碳汇交易、GEP核算、生态产品价值转化，短期看牺牲一部分粗放发展的机会，长期看筑生态安全屏障，拓展永续发展空间。
