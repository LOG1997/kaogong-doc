# 马克思主义哲学

## 绪论

哲学是理论化、系统化的世界观，是**世界观和方法论**的统一；是对自然知识、社会知识和思维知识的概括和总结。

哲学和具体科学：具体科学是哲学的基础；哲学给具体科学以世界观和方法论的指导。

哲学要解决的基本问题是：物质和意识的关系问题。

马克思主义有四个基本内容：

1. 唯物论

2. 辩证法

## 唯物论

### 物质与意识

物质不依赖于意识存在，物质的唯一特性是客观实在性。

**运动**是物质的根本属性和存在方式。

------------------

意识的本质是人脑对客观存在的**主观映像**。

社会实践，特别是劳动在意识产生过程中起着决定性作用。

------------------

二者关系是辩证的关系：

1. 物质决定意识——一切从实际出发

2. 意识对物质具有反作用。

### 绝对运动和相对静止

世界上一切事物的存在和发展，都是绝对运动和相对静止的统一。

## 唯物辩证法

有两大特征（事物的普遍联系、事物的永恒发展）与三大规律

### 唯物辩证的总特征

**联系**和**发展**的观点是唯物辩证法的总观点和总特征。

#### 事物的普遍联系

1. 客观性

    原理：联系是事物本身所固有的，**不以人的意志为转移**。

    方法论：不可主观臆造联系；可以根据事物固有联系，改变事物状态，调整原有联系，建立新的联系（也是客观的联系）。

2. 普遍性

    原理：联系无处不在，联系无时不有，**世界上不存在孤立的事物**。

    方法论：用普遍联系的观点看问题，反对形而上学的孤立观点

3. 条件性

    原理：任何一种联系总是在一定条件下的联系。

    方法论：要善于利用有利条件，善于化不利为有利

4. 多样性

    原理：事物联系的主要方式有内部联系和外部联系、直接联系和间接联系、必然联系和偶然联系、本质联系和非本质联系等。

    方法论：把握不同形势下的各类联系。

5. 系统性

    原理：系统由要素构成，系统和要素的关系，即整体和部分的关系。**整体主导低位，部分是服从关系和服务于整体**，关键部分甚至对整体功能起决定作用。

    方法论：梳理全局观念，立足整体、统筹全局；必须重视部分的作用。

#### 事物的永恒发展

原理：发展是前进上生的运动。发展的实质是新事物的产生，旧事物的灭亡，新旧事物区分的标志是是否同事物发展的必然趋势相符合。

方法论：坚持用发展的眼光看问题，坚持与时俱进，培养创新精神，促进新事物的成长。

新事物与旧事物的关系是一种取代和超越。

### 三大规律

三大规律：对立统一、量变质变、否定之否定。

三大规律就是在讲事物是怎么发展的。

发展的动力是**矛盾（对立统一）**；
发展的方向道路是**否定之否定**，方向是前进的，道路是曲折的，不断前行然后不断自我否定，螺旋上升；
发展的形式是**量变质变**。

#### 对立统一（矛盾）规律

1. 矛盾的基本属性

    斗争性：矛盾的双方是相互排斥、相互斗争的；是绝对的，无条件的。

    同一性：矛盾的双方是相互依存、相互贯通的，一定条件下可以相互转化；是相对的，有条件的。

    斗争性寓于同一性之中。

2. 矛盾的普遍性（无条件的、绝对的）和特殊性（有条件的、相对的）

    * 普遍性

        事事有矛盾，时时有矛盾。所以要敢于承认矛盾，全面地看问题，不要反对、逃避矛盾。

    * 特殊性

        不同事物矛盾各有特点；同一事物的矛盾在不同发展过程中各有不同特点；构成事物诸多矛盾一级每一矛盾的不同方面各有不同的性质、地位和作用。所以要求我们坚持具体问题具体分析。

    * 二者的辩证关系

        普遍性寓于特殊性之中。

    * 重要表述

        承认矛盾的普遍性是坚持唯物辩证法的前提。

        认识矛盾的特殊性是正确解决矛盾的前提。

        矛盾的特殊性决定事物的特殊本质，分析矛盾的特殊性是认识事物本质的基础。

        矛盾的普遍性和特殊性辩证关系是原理，是关于矛盾问题的精髓，是马克思主义基本原理和中国具体实际相结合的哲学基础。

3. 矛盾的不平衡性

    矛盾有主要矛盾和次要矛盾，主要矛盾处于支配地位，对**事物的发展**起决定性作用，次要矛盾处于服从地位，对事物发展起影响作用。

    矛盾有主要方面和次要方面，主要方面处于支配地位，对**事物的性质**起决定性作用，次要方面处于被支配地位，对事物的性质有一定影响。

4. 内外因原理

    内因是事物的内部矛盾，是**事物发展变化的根据**。

    外因是一事物与其他事物相互影响和相互作用，是**事物发展变化的条件**；外阴必须通过内因起作用。

#### 量变质变规律

1. 量变

    数量增减和组合要素排列次序变动，体现了事物发展渐进过程的连续性。

2. 质变

    事物根本性质的变化，体现了事物渐变过程和连续性的中断。

二者的辩证关系：

量变是质变的前提和必要准备；质变是量变的必然结果；质变又为新的量变开辟道路，使事物在新质的基础上开始新的量变。

#### 否定之否定规律

* 辩证的否定观

➀ 辩证的否定是包含肯定的否定
② 辩证的否定是事物的自我否定
③ 百年正的否定实质是“扬弃”
④ 辩证的否定是发展和联系环节

* 否定之否定规律

否定之否定规律表明：事物的发展总方向、总趋势是前进的、上生的，事物发展的具体道路又是曲折的、迂回的。

## 认识论

### 实践和认识

实践是指**人类能动**地**改造世界**的社会性的**客观物质活动**。时间是直观见之于客观的活动，是沟通主观和客观的桥梁。

#### 实践的特征

客观物质性（客观的，会受客观制约）

自觉能动性（人类自觉、有意识的活动）

社会历史性（一定的社会关系中进行实践活动）

直接现实性（实践高于理论品性）

#### 实践和认识的辩证关系

实践是认识的**来源**；

实践是认识发展的**动力**；

实践是认识的**目的和归宿**；

实践是检验认识是否具有真理性的**唯一标准**。

> 实践 → 产生认识 → 再实践。即“认识来自于实践，反过来再去指导实践”

### 真理

真理是客观事物及其规律在人的意识中的**正确**反映，是标志主观和客观相符合的范畴。

> 真理一定是正确的。

#### 真理的特征

* 客观性

    真理的内容是客观，真理的内容来自于不以人的意志为转移的客观实在。

    实践作为检验真理的标准也是客观的。

* 绝对性与相对性（统一客观真理的两重属性）

    绝对性说的是真理的绝对属性（正确的）。

    相对性说的是真理是在发展的，相对于条件是正确的。
