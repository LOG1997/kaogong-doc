## 加快建设健康中国

### 新时代卫生与健康工作方针

以**基层**为重点，以**改革创新**为动力，**预防为主，中西医并重**，把健康融入所有政策，人民共建共享。

目标：“十五五”时期是实现到**2035年建成健康中国**目标的关键时期。健康中国，是**均衡普惠、优质高效**的健康中国。

### 健康中国措施

1. **预防**是最经济最有效的健康策略

2. 全面提高医疗服务水平是建成健康中国的一项重点任务

    **促进分级诊疗**

3. 改革是卫生与健康事业发展的强大动力

    **医疗、医保、医药协同**发展作为医药卫生体制改革的主攻方向。

4. 保障人民健康需要建强卫生与健康系统干部人才队伍
