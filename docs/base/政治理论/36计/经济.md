## 扩大**内需**是战略之举

让内需称谓拉动经济增长的**主动力**和**稳定锚**。

### 原则方向

1. 社会再生产的四个环节：

    ::: details 点击展开查看答案
    生产、分配、流通、消费

    （也就是创造（决定性作用）、确认、交换（让渡所有权，比如去商场消费买衣服）、消耗（穿在身上））

    （这就是说的国内大循环）
    :::

2. 扩大内需和扩大开放不矛盾

### 重点举措

1. 坚持惠民生和促消费

2. 扩大***消费**最根本的事：促进就业，完善社保，优化收入分配结构，扩大中等收入群体，扎实推进共同富裕。（消费起基础性作用）

3. 完善扩大投资机制：拓展**有效投资**空间；适度超前部署新型基础设施建设（投资起关键性作用）

4. 继续深化**供给侧结构性改革**。（目的是以自主可控、稿质量供给适应满足现有需求。**新需求引领新供给，新供给创造新需求**）。

## 做强做优做大实体经济

地位：实体经济是一国经济的**立身之本**，是财富创造的的**根本源泉**，是国家强盛的**重要支柱**

### 具体措施

1. 制造业是实体经济基础

    坚持全面推进**传统产业**转型升级，积极发展**新兴产业**、超前布局**未来产业**并举

2. 金融是实体经济的血脉

    坚持把金融服务实体经济作为根本宗旨。绝不能脱实向虚。
