    加强**原始创新**和**关键核心技术攻关**

    全面提升基础研究水平

3. 建设强大国内市场 加快构建新发展格局

    国内大市场：国内统一大市场

    新发展格局，主体__：

    ::: details 点击展开查看答案
    国内大循环为主体、国内国际双循环相互促进
    :::

    新需求与新供给的关系

    ::: details 点击展开查看答案
    新需求引领新供给，新供给创造新需求
    :::

4. 扩大高水平对外开放 开创合作共赢新局面

    现在实行的就是制度型的开放：扩大高水平对外开放 开创合作共赢新局面

    重点开放的领域是：

    ::: details 点击展开查看答案
    服务业（制造业很强了，不用开放了）
    :::

5. 优化区域经济布局 促进区域协调发展

    经济大省挑大梁、海洋经济高质量发展。

    * 海洋经济高质量发展的五个**更加注重**：

        更加注重**创新驱动**

        更加注重**高效协同**（陆海统筹，山海联动）

        更加注重**产业更新**

        更加注重**人海和谐**，海洋资源开发和保护（高质量发展=开发（发展）+保护（高质量））

        更加注重**合作共赢**

    * 海洋经济高质量发展六个具体工作

        加强**顶层设计**和政策支持：编制“十五五”海洋经济发展规划（**还没编制好**）；鼓励引导社会资本参与

        提高海洋科技**自主创新**能力

        **做强做优做大**海洋产业

        加强**海湾整体规划**

        加强海洋生态**环境保护**

        深度参与全球海洋治理

    所以有**两方面措施** ：稳定房地产市场、积极有序化解地方政府债务风险
