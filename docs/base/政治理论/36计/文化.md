## 国家科学技术奖励大会

### 目前取得的成就

我国正从全球科技参与者、贡献者向**开拓者、引领者**加速转变。

成为创新力**上升最快**的国家之一。（创新能力大概只排第九）

### 六点要求

1. 增强科技创新**体系化**攻关能力

   科研任务推进，要前瞻布局建设重大科技基础设施，在一些基础条件上要**自主保障**。

   科技力量建设上，要支持国家战略科技力量与其他科技力量**合作攻关**。

    科技创新联动上，要形成**央地协同、区域联动**，**因地制宜**探索创新发展路径，确立**比较优势**。

2. 推动**科技创新和产业创新**深度融合（理论创新和落地转化）

    **科技创新**要突出**应用导向**。

    **产业创新**要提出科学问题，强化**企业创新主体地位**。（**产业出题，科技答题**）

3. 大力培养优秀青年科技人才

    注重在**科研一线**发现和培养更多优秀青年科技人才。

4. 提高科技创新投入**效能**（要看到效果）

    **财政经费**在科技投入中具有**风向标**作用

    重点向**战略性、关键性**领域倾斜。

    健全重大科技任务**央地投入共担**机制，合理配置中央和地方财政资金，引导地方聚焦国家战略需求，加大研发投入。

5. 用好科技评价指挥棒（好像考核评价都是指挥棒作用）

    加快“**破四唯**”（唯论文、唯职称、唯学历、唯奖项）

    **科技评价重在按科研规律办事**。

6. 加强科技伦理和安全治理

> 2025国家爱科学技术奖获得者陈立泉（锂电池领域）、贲德（雷达技术）

## 纪念中国工农红军长征胜利90周年大会

### 长征的常识

大会召开时间：2026.10.22召开

长征路线：瑞金——（于都）——强渡想将——过乌江——遵义会议——四渡赤水——巧渡金沙江——强渡大渡河——飞夺泸定桥——翻越夹金山——过草地——陕北吴起会师——甘肃会宁会师——将台堡会师

长征的直接原因：第五次反围剿失败

长征的根本原因：左倾教条主义

长征时间：1934年10月至1936年10月

### 制胜之道

1. 依靠**党**的正确领导

    1935年1月召开遵义会议，确立了毛泽东同志在党中央和红军的领导地位，开始形成**以毛泽东同志为核心**的党的第一代中央领导集体，开启了党**独立自主**解决中国革命实际问题新阶段。挽救了党、挽救了红军、挽救了中国革命。

2. 依靠坚定的革命意志

    具有**崇高理想和坚定信念**的队伍是不可战胜的

3. 依靠独立自主、实事求是

    马克思主义基本原理只有同中国具体实际紧密结合，才能解决中国的问题。

4. 依靠广大人民群众支持

    事件时间先后顺序：十送红军（苏区送别红军）、于都夜读（百姓宋床板搭浮桥送红军）、半条被子的温暖（红军减一半被子给老百姓）、彝海结盟（刘伯承和彝族首领歃血为盟）

    人民群众永远是党和人民军队的力量源泉和坚强后盾
