# 翻译推理

## 翻译规则

* 前 → 后

如果...那么...、就、都、一定

* 后 → 前

只有...才...、不...，不...、除非...，否则不...

除非A，否则B：-B → A

谁必不可少，谁在箭头后

* 复杂关系

且关系：两者同时成立，缺一不可 = **A且B**

或关系：两者至少成立一个 = **A或B**

要么...要么...：两者有且只有一个成立 = A⊕B
​
至多一个：-A或-B

## 推理规则

* 逆否等价

A → B = -B → -A

即：肯前必肯后，否后必否前；否前肯后无必然结论。

* 或关系否1推1

A或B为真时：-A → B；-B → A

* 德摩根定律

-（A且B）= -A或-B
-（A或B）= -A且-B

## 小tips（永乐小典）

1. 一个翻译推理的推出关系中，选项优先考虑否后推否前，其次肯前推肯后。

2. 题干中有两个推出关系且串不起来的情况，优先考虑第二个关系，其次考虑第一个关系。

3. 多个推出关系能串，优先考虑首尾，其次考虑其他。

4. 只有A，才B，进而/从而C。翻译为：C → B → A，且优先考虑这句话。

5. 问不可能/不符合/没有遵守要求，优先找矛盾（A → B（-A或B）的矛盾为A且-B）

6. 给结论找条件，优先考虑消消乐。

7. 题干特征：翻译+无确定信息，选项为确定结论：（1）A → B；-A → B，那么B一定为真。（2）A → B；A → -B，那么-A一定为真。（3）A → -A，那么A一定是真。（**二难推理**）

8. 三个至少有两个 = 两个至少有一个
