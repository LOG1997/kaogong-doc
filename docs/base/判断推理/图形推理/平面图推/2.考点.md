# 主要考点

## 属性类考点

图形的宏观属性：对称性、曲直性、开闭性。这种题型很容易看出来，可以在看到题目就进行判断，具有最高优先级。

### 对称性

分为轴对称、中心对称、两者皆有。

笼统的考点：

1. 对称属性分组：按照轴对称、中心对称、不对称进行分组

2. 周期与遍历：按照不同对称属性进行周期排列

3. 对称属性与位置关系：常见于不同对称属性图形呈周期固定的上下、左右、内外关系

对于轴对称还有很多细化的考点：

1. 对称轴数量：对称轴数量恒定或者递增（5+1题型）（**常见**）

2. 对称轴方向：方向固定或周期旋转（5+1题型）（**常见**）

3. 对称轴穿越（两侧）要素：对称轴均为一条且无固定方向规律是，重点观察穿越（两侧）要素（如点、线、面、要素数量），这一部分是**难点**，不常见，但是要注意有这种题型。比如**对称轴两侧分别有多少个元素**或者**对称轴穿越元素的属性（点、线、面、角、要素数量）**

4. 对称轴间的关系：常见于每组图形存在不知一个轴对称图形的情况，分析不同对称图形间对称轴关系（**平行、交叉、垂直**）

### 曲直性

曲直性规律常见于分组分类题目中。

考点：

1. 周期排列：纯直线、纯曲线、曲直结合

2. 整体分类：六幅图形，分为全直图形和全曲图形

3. 局部嵌套分类：结合图形内外结构进行考察，比如内外结构的曲直图形，也可能是上下左右结构的曲直图形。

### 开闭性

体感出现明显的**外漏线条**、或者由**生活化图标**、**英文字母**、**汉字**组成，应考虑图形开闭性。

1. 全封闭图形：完全闭合的内部空间，不存在向外延伸的线头

2. 全开放图形：不包含任何闭合的内部空间

3. 半开半闭图形：图形既包含封闭内部空间，又带有**向外的延伸线条**（应该不常见吧，但是考到了就是难点）

## 位置、移动和相邻比较

**这个算是难点**

需要观察元素的动态轨迹与结构重组优化。

### 位置关系

1. 静态位置关系：

   基础方位关系：上下左右、内外包含

   空间结构关系：连接状态（相离、相切、相交）、相隔距离、相隔元素（面、线）

2. 动态位置关系：

   局部元素发生空间方位变化：平移、旋转、翻转

### 相邻比较

题干图形的整体轮廓格式相同或接近，但内部元素不遵循全局的平移、旋转和翻转，需要采用局部视角去对照。

1. 区域递推：相邻图形只有特定区域发生变化，且变化区域位置发生规律性推移。
   主要有：行/列递进、顺/逆时针区域递进

2. 变化数量的递推：相邻图形中有状态发生改变的元素数量呈现明显规律

3. 局部元素的交替/替换

## 数量规律

宏观属性不能观察到规律，图形外在轮廓差异大，明显的线条交错或者零散的区块分割时，考点通常指向数量类。
如果是数数量的话，比如曲直交点，直曲线，需要把几者分开数，这样后续如果是加减的关系更方便计算

### 点

识别特征：

1. 图形交点/端点数量比较清晰，且数量呈现递推变化

2. 明显的曲直交点或图形切点

3. 图形存在外框，且内外框上交点存在对比规律，分别数外框交点数量

考点：

交点总数:曲直交点，切点，内外方位点（主体外框和内部点）

### 线

特征：

1. 开放式框架，网状结构；

2. 直曲线对比分明；大量生活化图形；

3. 连通性很强的复杂图案

考点：

1. 数直曲线数量（曲直分开数，方便后续加减），可能是相等，也可能存在数量上的规律关系

2. 一笔画图形（后面单独出一节）（与点结合）

3. 横竖线

4. 平行线

5. 公共边（与面结合比较常见）

#### **一笔画**

方法一:数奇点数量，也就是从一点出发，有奇数条线的端点，奇点数量除以2就有多少笔画

方法二:去除封闭面后，数剩下来的有多少笔画，那这个图形就是多少笔画

方法三:简单的图形直接观察能否一笔连通就可以了

#### 横竖线

横竖线作为特殊线段分别统计

#### 平行线

如果存在明显的平行图形，闭合面的嵌套，图内做切割的场景，可能就是平行线的考点

如果出现了三条以上的平行线段，不考虑此考点

#### 公共边

特征:

1. 所有图形都有两个面且为线相邻的关系

2. 或者所有图形都有一个标志面（如黑块）。

考察的是两个面间公共边或者标志面与各个面公共边数量关系

### 面

关于面的数量关系规律，主要依靠做题中的积累，探究清楚有哪些考点，怎么出题

基础考法：图形中独立封闭区域的总数，规律可能为常数、等差数列、加减规律

进阶考法：

1. 面与面之间的关系（通常为点相连、线相连）

2. 特殊面的提取：

   最大面/最小面，观察其形状特征（几边形）、属性特征（曲直、对称）、外框关系（相同、对称对应关系）、相邻面之间的关系（主要是相邻面数量）

   特定边数的图形数量（三角形、四边形），是否存在统一或者数列规律

   如果存在黑块、阴影块、特殊标记块，需要提取特殊块单独辨析，重点看其边数（总边数、与其余面相邻边数、占外框边数）

   相邻面数

   面积情况

   图形属性情况

3. 面积换算关系：

   图形内部是否将整体进行了等面积分割，不同面之间是否存在整数倍的面积关系

### 素（独立元素与部份数）

特征：图形缺乏统一的连接框架：由多个零散的小图形、小符号（五角星、圆圈、方块等）组成

考点：

1. 种类数：画面中包含了集中不同形状的独立元素

2. 总个数：不区分形状、画面中所有独立小元素数量总和

3. 部分数：只要相互连接，就算做一部分。，**面对极度零散杂乱的图形，优先统计部分数，通常呈现规律性递增**

### 角（冷门考点）

无独立特征，点、线、面、角、素规律失效以后，作为兜底考点启用。

考点：就是i般来说直角的考察（直角个数）

## 图形计算类

外部框架高度一致，但内部填充的颜色、图案不遵循简单的移动规律时，考点通常指向计算类考点，核心在于将图形“代数化”。

两种核心解法是黑白运算和等量代换

考点：

1. 面的计算

   通常就是计算白+黑、黑+白...等图形计算

2. 线的计算

   去同存异、去异存同

3. 多色叠加（比较复杂的规律了，应该不会多考）

   加入灰块、斜线等图形。

4. 异形叠加（应该也不会多考）

   跟黑白相加类似，只是说运算主体不一样了，比如实心圆+空心圆=空心圆

## 等量代换

不同元素之间内在价值换算。因为存在两个变量（比如星星和圆），直接观察无法得出规律，必须通过代数思维将双变量转化为单变量。

1. 第一步：劣等是提取特征，观察内部元素数量，寻找数量呈线性递增或者递减趋势。

2. 第二步：带入换算比例，元素间的换算比例大多数是1：2或者1：3（比如1个图形A=2个图形B），将该比例带入所有图形中，将所有图形转换成数字进行计算。

3. 第三步：验证数列规律

1. 黑白块

2. 汉字、字母、数字类

3. 标记图形类
