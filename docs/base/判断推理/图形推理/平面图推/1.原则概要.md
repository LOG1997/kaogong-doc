# 平面图推

## 题型

### 递推格式

横向给出五幅图形，要求推导第六项

**做法**：<u>“规律的从始至终贯穿性”</u>，统一规律、递推/周期考点、相邻比较

1. 统一规律：
    六个图形必须具备某种绝对一致的特征——**点、线、面、角、相同的图形属性（对称、曲直、开闭）**

    首先对称性很容易判断，第一眼就可以看出对称性，后面再去细化判断考察的是哪个方向

2. 递推考点

   主要涉及到的是要素的等差或者周期变化，**定向移动/旋转**等规律。可以定位到要素数量（点、线、面的递增递减）或者要素的定向移动/旋转

3. 相邻比较

   在递推无果后进行判断

   相邻图形中存在固定的变化逻辑（比如，相邻图形中只有一行/列发生变化或者不发生变化）

### 公式对照格式（三三分列）

给出两组图形，左侧三个，右侧两个，要求推导右侧第三个

**做法**：快速锁定左侧图形的规律，带入右侧图形验证。**平面叠加运算（直接叠加、去同存异、去异存同）**、**位置平移**、**宏观或者微观数量**。

### 九宫格格式（3×3矩阵）

图形排列在九宫格中，推导空白格子

**做法**：其实就是分组图形逻辑，即多组图形套用相同的格式。

1. 横向/纵向/黑白运算：优先横向观察，考察第一行三个图形的拼合和叠加
2. 元素递推：某种单一元素在九个格子内整体步长移动以及旋转翻转和数量变化
3. 遍历：某种图形的遍历规律
4. 对称考点（很少）

### 分类分组（6个图形分两组）

题目给出六个带有序号的图形，按照统一逻辑分成3对3的两组

**做法**：这种题型不是找公式，是找“基因”

1. 图形的宏观属性（对称性、曲直性、开闭性或者图形元素的组成部分数）

### 空间与独立题型

题目呈现平面展开图、立体方块、不规则碎片或被切割的几何体。

**做法**：不是对称性、面、线、点的考察，是一种独立的题型考点

1. 平面拼合

2. 立体拼合

3. 切割截面

## 思考顺序

第一：肯定先考虑图形的宏观属性（对称、曲直、开闭）和最大/小面的宏观属性

第二：当宏观属性没有明显规律的时候，就去考虑面、线、点、角的关系
