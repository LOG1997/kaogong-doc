# 题型特殊说明

* 因果论证+削弱

    考虑从两个方向进行削弱：1️⃣. 他因；2️⃣. 因果同时出现，因果倒置

* 双人互怼+削弱

    常考否论据。因为这样的论点太简单了，只能从论据下手。

* 实验类论证+论据是单组调查或对比实验，论点是实验后结论

    削弱：

    1. 实验起点不一致/实验样本特殊：实验样本本来就具有某种特质，不是变量导致的。

    2. 实验过程有其他变量

    3. 实验环节设计不合理

    4. 实验结果持续时间不足

    5. 对比实验，补充的其他数据存疑

* 前提类题目

    一般选必要条件（没他不行）

* 设问“与上述论证/逻辑错误/对话方式一致”的

    解题思路：

    1. 字母标记：

        适用于简单的结构，比如“熊猫是动物，青蛙是动物，所以熊猫是青蛙”之类的题目。

        把题干要素使用字母标记A,B,C，在选项种也使用A,B,C来做标记，。

    2. 推理结构：

        出现明显的逻辑关联词，可以翻译后看推理结构的。也就是充分条件/必要条件那一套。

    3. 文段结构

        没有充分条件/必要条件那样的逻辑关联词，但是句式很明晰，可以梳理句式结构

        比如“a有利于b，b有利于c，所以a有利于c”这样式的。

    4. 逻辑错误

        题干中存在明显逻辑错误。比如把包含关系错误理解为并列关系之类的。

* 缓解忧虑/担忧类型的题目

    题目特征：因某件事产生了负面情绪，怎么缓解/消除/安抚这种情绪。

    解题模型（程度从强到弱）：

    1. 瓦解负面本身，把问题变优点。

    2. 认知重构，把结果从坏变好，改写未来结果

    3. 降低威胁感，弱化问题程度

    **易错点：泛化的安慰之类的**

* 与题干论证错误相似

解题思路：积累常见论证错误类型

1. 偷换概念：概念不一致

2. 转移论题：话题转变

3. 以偏概全

4. 不当类比：性质不同、可比性不足的事物强行对比

5. 自相矛盾

6. 关系混用：矛盾关系与反对关系、包容关系与并列关系、并列关系与交叉关系

7. 循环论证：同义反复

8. 诉诸权威
