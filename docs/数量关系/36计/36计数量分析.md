# 数量分析方法

## 代入方法

代入排除法的代入原则共分为两类
一类是适配最值类提问的最值原则，按提问的最大、最小指向选择对应方向的数值开始代入，保证代入的方向性;
另一类是无最值要求时适用的好算原则，优先选择计算简便的数值代入，计算难度相近时可按选项顺序代入。

**最值代入的化，问题问的是最小值就从最小值开始代入，问的最大值就从最大值开始代入**

### 多位数、余数问题

将选项代入到题干信息中，这一类问题基本都可以解决。

### 选项充分类

选项是一组数、选项可以转化为一组数。
