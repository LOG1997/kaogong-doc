# 加强削弱

若某个选项为真，会让题干更可信/更不可信。

加强题：让论点更可信

削弱题：让论点更不可信

前提题：找论证成立不可缺少的条件

不能加强/削弱的题：反向判断

## 论证的基本结构

论点、论据之外还有隐含前提，即题干中没有直接说出来的，但是论证成立必须依赖的条件。

例如：经常喝茶的人患小耳麻痹症概率低，隐含前提就是：小儿麻痹症与喝茶有关，如果这个前提不成立，论证就会变弱。

## 论证链条

加强削弱题如果出现了隐藏前提，那么判断的核心就是看论证链条是否稳固：

论据 → 隐含前提 → 论点

前后一定要串的上。

**加强削弱可以不用通篇的读，先看论点，再找论据**

论证链条不要只看题干说了什么，号要看论据到论点之间相隔了多远。

### 一段式论证

仅包含一个核心论证关系，即他是一个或者多个并列论据直接推到结论i一个的论证结构，论据和论点之间不存在任何中间概念，也就是说没有隐含前提。

这类题型常见的漏洞就是：

调查样本是否具有代表性？

调查方式是否具有科学性？

数据是否真实可靠？

### 二段式论证

论据和结论的论述主题有重复内容，但不完全一致，需要逻辑链条或者隐藏前提进行串联。

两种情况

1. 论据：A → B；结论：A → C，二者起点一致，落点不同，需要A → B加上B → C才能得到A → C。

2. 论据：A → C；结论：B → C，二者落点一致，起点不同，需要A → C加上B → A才能得到B → C。

这一类加强削弱题的关键就是**搭桥/拆桥**。

## 论证的基本形式

### 因果论证

从直接相关的现象、道理推出结论。

这一类题逻辑漏洞有**因果倒置/另有他因**。

比如：

结论是夜跑的人睡眠更好。那么他的漏洞可能就有：

1. 因果倒置：睡眠更好的人更喜欢夜跑

2. 其他原因导致睡眠更好

如果要加强这一类论点的话，就需要**排除其他原因**、**补充其他论据**等。

如果是削弱这一类论点的话，可以**其他原因**、**因果倒置**、**提出反向机制**等方法。

### 归纳论证

从部分样本推出总体结论。

常见结构有：

#### A（部分）具有A1的特性，因此B（总体）具有A1的特性

这个结构常见的加强削弱方向是从**样本是否具有代表性**的角度去考虑的。

加强方向：科学性、样本足够大、覆盖足够广

削弱方向：样本来源单一、样本与总体差异明显、调查方式不公平等。

### 实验论证

从实验结果推出某广义的结论。

常见形式：使用了某种方法，结果符合预期，因此对应理论成立。

常见漏洞：

实验设计是否合理、变量是否相同、样本是否足够等。

加强方向：让实验更加科学严谨

削弱方向：破坏严谨性

### 类比论证

从A对象推出B对象

典型形式：A成功了，B和A相似，所以B也会成功；A适用某方法，B和A类似，所以B也适用。

常见漏洞：

其他点二者是否相似。

加强方向：其他点都高度相似

削弱方向：其他变量不相似

### 对策论证

为了达到目的，应该采取措施。

典型形式：为了解决问题G，应该采取措施M；为了达到目的G，应实行政策M。

其中的隐含逻辑是G与M之间有关系。

## 加强削弱的对象

作用于三类主体

* 作用于论点

直接肯定或者否定结论。

力度：通常最强

* 作用于桥梁

搭桥或者拆桥。搭桥就是建立论据和论点之间的关系；拆桥就是切断论据和论点之间的逻辑链联系。

力度：通常力度也很强，尤其在二段式论证当中，力度一般是最强的选项。

识别技巧：选项同时出现论据和论点的关键词。

* 作用于论据

补强或者攻击证据基础

力度：取决于对论据攻击的破坏程度

如果只是指出样本不够全面，力度一般；如果是指出样本完全偏离总体，力度较强；如果直接证明论据反了，力度极强。

## 加强削弱的力度比较

按照一下以下顺序进行梳理：

1. 先看方向是加强、削弱还是无关

2. 看题干论点的强弱，论点越绝对，越容易被反例削弱。

## 常见削弱方式

### 否定论点

直接说明题干论点不成立。

### 拆桥

切断论据和论点之间的联系。

否定力度也很强：⭐⭐⭐⭐⭐

### 因果倒置

指出题干把原因和结果弄反了。

强度五颗星：⭐⭐⭐⭐⭐

### 否定必要前提

指出体感论证以来的关键前提不存在

强度五颗星：⭐⭐⭐⭐⭐

指出题干使用的论据不可靠。

默认强度：⭐⭐⭐到⭐⭐⭐⭐⭐。

如果是直接证明论据反立，可以达到五颗星⭐⭐⭐⭐⭐。

指出题干所说结果并非由题干原因导致，而是由其他因素导致。

默认强度：⭐⭐到⭐⭐⭐⭐⭐。

如果体感说A导致B，可以指出：有A，但没有B。

默认强度：⭐⭐到⭐⭐⭐⭐⭐

如果说题干说A导致B，可以指出：没有A，也有B。

## 标准做题流程

1. 审问法：先看问法：加强？削弱？前提？不能加强？不能削弱？最能支持？最能质疑？

2. 找论点：圈出题干最终观点，重点关注因此、所以、由此可见；专家认为、研究人员认为；应当、建议、可以推出；多人观点中题目要求针对谁

3. 抓论据：找出题干用什么来支持论点：调查？数据？实验？现象？案例？类比？措施建议？

4. 判断结构：判断论证属于哪种类型：因果、归纳实验、类比、对策、二段式搭桥、数据比较

5. 预设答案：从论据到论点，差了什么？

6. 比较选项
