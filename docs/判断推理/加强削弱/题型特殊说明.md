# 题型特殊说明

* 因果论证+削弱

    考虑从两个方向进行削弱：1️⃣. 他因；2️⃣. 因果同时出现，因果倒置

* 双人互怼+削弱

    常考否论据。因为这样的论点太简单了，只能从论据下手。

* 实验类论证+论据是单组调查或对比实验，论点是实验后结论

    削弱：

    1. 实验起点不一致/实验样本特殊：实验样本本来就具有某种特质，不是变量导致的。

    2. 实验过程有其他变量

    3. 实验环节设计不合理

    4. 实验结果持续时间不足

    5. 对比实验，补充的其他数据存疑

* 前提类题目

    一般选必要条件（没他不行）

* 翻译推理题
