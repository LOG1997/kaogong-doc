# 组合问题

从若干要素中按照特定条件进行筛选和匹配。

可以把题目条件翻译为或/且的形式，进行推理。

其实也是之前逻辑推理类型题目的延申，把题干中提到的条件都转化为

## 36计

* 最大信息+选项

题干里面，被提到次数最多的那个条件，叫最大信息。他是推理的起点。过程中结合选项进行排除。

最大信息推理不出答案是，通过假设最大信息来进行推理

* 二维表

什么时候用：题干出现一对多，且已知信息中有“是/不是”。

方法：人物写在左手竖列，行为写在顶部横列。条件为“是”的打√，条件为“不是”的打“×”，完成后返回根据题干的条件（数量限制）对照表格修改。

还有数独类的题目也是画二维表。

* 推理模型

何时用：题干有逻辑关联词+数量限定

怎么用：翻译A → B，假设A成立，结合题干点找矛盾

* 数字分组

何时用：题干有明确分组

怎么用：先分析组内成员人数，再结合题干数量推理。
