# 逻辑推理

## 基础命题

### 充分条件

充分条件的核心是：前面的条件一旦成立，后面的结果必然成立，这是一个推理的过程。A→B

常见的表达包括：

* 如果 A，那么 B。

* 只要 A，就 B。

* 若 A，则 B。

* 一旦 A，就 B。

* 凡是 A，都 B。

* 除非 A，否则 B（-A→B）。

* A 是 B 的充分条件等。

常见的充分条件例子：

考试得满分是考试及格的充分条件。

小明获得冠军是小明进入前三名的充分条件。

X 大于 100 是 X 大于 10 的充分条件。

其实就类似于一个集合的概念，A 是被 B 包含的。

**充分条件：有它就行。必要条件：没它不行。**

充分条件的必然与可能：

例如：如果明天下雨，那么我明天会带伞。
必然性：明天下雨，我明天一定会带伞。
可能性：明天不下雨。我明天可能带伞，也可能不带伞。

### 必要条件

如果一个命题的存在必须以另一个命题成立为前提，即如果没有 A 则 B 就必然不成立，那么 A 就是 B 的必要条件。A←B

结合前面说到的充分条件，可以说：当 A 是 B 的充分条件时，B 是 A 的必要条件。
A → B 等价于 B ← A。

常见例子：

一个图形是四边形，是它成为正方形的必要条件。

年满 18 岁是去网吧上网的必要条件。

通电是电灯正常发光的必要条件。

考试成绩大于 60 分是考试成绩达到 90 分的必要条件。

常见的表达包括：

* 除非 A 才 B

* 只有 A 才 B

* 不 A 就不 B

* 没有 A 就没有 B

* B 离不开 A

* 除非 A 否则不 B

* A 是 B 的关键、基础、核心、前提、必须、必不可少、不可或缺、本质要求。

必要条件的必然与可能。其实就与充分条件的相反。

### 必要条件逻辑的逆否转换

必要条件的必然性推理只有一条：当 B 不成立时，A 一定不成立。**写作-B→-A**

得到结论：**A→B 时，- B→-A。这就是充分必要逻辑的逆否转换。**

必然性结论：

当 A → B 时，必然性结论有 A→B、-B→-A。

用中文表示，肯前必肯后，否后必否前。

可能性结论：

当 -A 成立时，B 可能成立，也可能不成立；当 B 成立时，A 可能成立，也可能不成立。

用中文表示：否前、肯后均不能推出确定结论。

### 充分必要条件

充要条件的核心定义是：有了 A 就一定有 B，且有了 B 也一定有 A；没有 A 就一定没有 B，没有 B 也一定没有 A。A⇔B

## 且命题

A 且 B 表示 AB 同时成立。

### 基础表达

并且、与、和、但是、同时、两者均、既要……又要。

且命题为真时，说明两个都成立；且命题为假时，说明至少有一个为假。

### 或命题

A 或 B 表示 A、B 至少一个成立，也可以都成立。

常见表述有：“或”“至少有一个”“不是……就是……”“至少有一个不”。

或命题成立的必然性与可能性:

因为或命题是至少有一个成立，也可以都成立。

所以，它的必然性是：非 A 成立，则 B 必然成立；非 B 成立，则 A 必然成立。

它的可能性是：A 成立，此时 B 可能成立，也可能不成立。

当是“且”和“否”的时候，就变成了“或”；当是“或”和“否”的时候，就变成了“且”。

比如，“甲值早班或乙值晚班”这个命题为假。那么这个命题可以转换为且命题，就是“甲不值早班且乙不值晚班”。

### 要么…要么命题

要么 A，要么 B，通常表示二者有且只有一个成立。也就是，A、B 不能同时为真，也不能同时为假。

A、B 的这种关系称为矛盾关系。

## 矛盾推理

### 矛盾的定义

两个命题不能同时为真，也不能同时为假，必定一真一假。通俗来讲，矛盾就是 A 与非-A。

### 德摩根定律

就是前面提到的且否命题，就变成了或，或否命题就变成了且。
-(A且B)=-A或-B

-(A或B)=-A且-B

通过对命题的否定，找到原命题的矛盾命题：实现且命题与或命题之间的相互转换。

充分条件、必要条件以及充分必要条件的矛盾

充分条件和必要条件可以转换为或。

充分条件

A→B在逻辑上即：  -A 或 B。

必要条件

B → A，逻辑上即：-B 或 A。

## 集合推理

### 所有的 S 都是 P

这个有两种可能：

S 与 P 完全重合，即 S 等于 P。

S 真包含于 P，即 S 是 P 的真子集。

### 所有 S 都不是 P

表示 S 与 P 之间完全排斥，没有交集。

### 有的 S 是 P

表示至少存在一个 S 是 P，即 S 与 P 有交集，但交集的大小不确定：可能是一个，也可能是多个，甚至可能是全部。

由“有的 S 是 P”无法推出“有的 S 不是 P”，因为也有可能全部 S 都是 P。

### 有的 S 不是 P

表示至少存在一个 S 不是 P，即 S 与 P 有部分排斥，但排斥的大小不确定，可能是一个，也可能是多个，甚至可能是全部。

“有的 S 不是 P”无法推出“有的 S 是 P”，因为二者可能完全排斥。

常见表述的否定及等价命题

-（有的人是）=所有人都不是
-（有的人不是）=所有人都是
-（有的是且有的不是）=所有都是或者所有都不是
-（并非所有都是）=所有都是
-（并非所有都不是）=所有都不是

## 命题间的关系梳理

### 矛盾关系

若两个命题为矛盾关系，则这两个命题必然一真一假。

### 反对关系

若两个命题为反对关系，则这两个命题至少有一个是假命题，即不能同时为真，但可以同时为假。

比如“所有”和“所有不”。

### 下反对关系

若两个命题为下反对关系，则这两个命题至少一真，即不能同时为假，但可以同时为真。

比如“有的”和“有的不”。

### 差等关系

有时也被称为从属关系，特点是单向真值的传递。在逻辑中类似于充分条件：即处于前端的命题为真，处于后端的命题必然为真；反之，处于后端的命题为假，前端的命题必然为假。
