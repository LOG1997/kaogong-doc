# 定义判断

要点:以题干为准，不凭常识扩展；以要件为准，不凭感觉判断；以匹配为准，不做过度联想

标准解题流程:

1. 先看题目问的什么

2. 定概念，判断题目是哪个概念

3. 拆要件，把概念拆成主体、时间、客体、目的、结果等要件

4. 比对选项

## 核心要件的拆解

### 主体与客体的拆解

主体即行为的发出者；客体即行为的承受者或指向对象

### 方式与目的的拆解

方式:行为主体实施行为所采用的手段，即“怎么做”

目的:题目中的配套方式想要达成的效果，即“做什么”

### 时间状态与属性倾向

时间状态是关注行为发生的阶段（未来时，进行时，过去时）

属性倾向是行为本身带有的性质限定

### 理科定义判断

有很多种类型:图片对比题、公式计算题

### 必要常识补充

核心成分:主谓宾
本体喻体:修辞手法比喻中使用到的
物理类变化和化学类变化

## 选项对比与择优原则

### 必要条件优先原则

判断选项时，应优先关注定义中的必要条件，如果某个要件定义成立的前提，那么选项一旦违反该要件，就可以排除

### 明确错误优先排除原则

如果选项与题干定义明确矛盾，可以直接排除

### 逻辑重复则出局原则

如果两个选项逻辑上是相同的，那么此时它们都应该排除
