# 图形找规律

技巧：点、线、面、角

## 一笔画图形题

1. 题目中会出现“日”，“田”，“五环奥迪”，“☆”的变形。“*田*”字是两笔画类型
2. 图形线条多且杂乱

### 捏球法判断一笔画

在图中从大到小圈出所有封闭图形（边不重合），然后看未圈出来的形状是否可以一笔画完，如果可以一笔画完，那这个图形就是一笔画。

## 找角

规律包括**数量**与**性质**。

数量没有规律时考虑性质

角的规律包括锐角、直角、钝角。

出现**锯齿状**大概率会是找角，并且是找**锐角**的数量。

出现**十字交叉**大概率是找**直角**的数量。

## 点

主要考察交点数量
需要注意直线与直线、直线与曲线、曲线与曲线的交点数量
