# 主要考点

## 属性类考点

图形的宏观属性：对称性、曲直性、开闭性。这种题型很容易看出来，可以在看到题目就进行判断，具有最高优先级。

### 对称性

分为轴对称、中心对称、两者皆有。

笼统的考点：

1. 对称属性分组：按照轴对称、中心对称、不对称进行分组

2. 周期与遍历：按照不同对称属性进行周期排列

3. 对称属性与位置关系：常见于不同对称属性图形呈周期固定的上下、左右、内外关系

对于轴对称还有很多细化的考点：

1. 对称轴数量：对称轴数量恒定或者递增（5+1题型）（**常见**）

2. 对称轴方向：方向固定或周期旋转（5+1题型）（**常见**）

3. 对称轴穿越（两侧）要素：对称轴均为一条且无固定方向规律是，重点观察穿越（两侧）要素（如点、线、面、要素数量），这一部分是**难点**，不常见，但是要注意有这种题型。比如**对称轴两侧分别有多少个元素**或者**对称轴穿越元素的属性（点、线、面、角、要素数量）**

4. 对称轴间的关系：常见于每组图形存在不知一个轴对称图形的情况，分析不同对称图形间对称轴关系（**平行、交叉、垂直**）

### 曲直性

曲直性规律常见于分组分类题目中。

考点：

1. 周期排列：纯直线、纯曲线、曲直结合

2. 整体分类：六幅图形，分为全直图形和全曲图形

3. 局部嵌套分类：结合图形内外结构进行考察，比如内外结构的曲直图形，也可能是上下左右结构的曲直图形。

### 开闭性

体感出现明显的**外漏线条**、或者由**生活化图标**、**英文字母**、**汉字**组成，应考虑图形开闭性。

1. 全封闭图形：完全闭合的内部空间，不存在向外延伸的线头

2. 全开放图形：不包含任何闭合的内部空间

3. 半开半闭图形：图形既包含封闭内部空间，又带有**向外的延伸线条**（应该不常见吧，但是考到了就是难点）

## 位置、移动和相邻比较

**这个算是难点**

需要观察元素的动态轨迹与结构重组优化。

### 位置关系

1. 静态位置关系：

   基础方位关系：上下左右、内外包含

   空间结构关系：连接状态（相离、相切、相交）、相隔距离、相隔元素（面、线）

2. 动态位置关系：

   局部元素发生空间方位变化：平移、旋转、翻转

### 相邻比较

题干图形的整体轮廓格式相同或接近，但内部元素不遵循全局的平移、旋转和翻转，需要采用局部视角去对照。

1. 区域递推：相邻图形只有特定区域发生变化，且变化区域位置发生规律性推移。
   主要有：行/列递进、顺/逆时针区域递进

2. 变化数量的递推：相邻图形中有状态发生改变的元素数量呈现明显规律

3. 局部元素的交替/替换
